# UTF Benchmark

A reproducible benchmark comparing the runtime impact of serving static assets encoded as **UTF-8** versus **UTF-16**.

## What it does

The benchmark renders a WebGL shader animation and tracks frame timing metrics (FPS, average frame time, and long-frame count). The same source files are copied into two output directories:

- `dist/utf8-control/` — standard UTF-8 encoded files with normal extensions.
- `dist/utf16-test/` — UTF-16 LE encoded files with custom extensions (`.1ink`, `.1ijs`, `.1iss`).

## Quick start

```bash
# Build the benchmark
npm run build

# Clean generated files
npm run clean
```

After building, open either of the generated `index.html` files in a browser:

- **UTF-8 control:** `dist/utf8-control/index.html`
- **UTF-16 test:** `dist/utf16-test/index.1ink`

> Note: Because the UTF-16 files use non-standard extensions, you may need to serve them via a local HTTP server that sets the appropriate `Content-Type` headers (e.g., `text/html`, `text/javascript`, `text/css`) for your browser to interpret them correctly.
